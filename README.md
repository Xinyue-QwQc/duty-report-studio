# 值班工作台

导入值班表，按日期和班次核对人员、分配区域，生成可复制或下载的日工作总结。新浏览器首次打开时显示导入指引。

## 首次使用

### 在本机运行

安装 Node.js 22.13 或以上版本，在项目目录运行以下命令，再打开浏览器访问 `http://127.0.0.1:5173`。本机模式仅监听回环地址，可以直接使用。

```sh
npm ci
npm run build
npm start
```

在 Windows 上完成构建后，也可双击 `启动工作台.cmd` 打开工作台。

### 部署到 Cloudflare Pages 并设置访问密钥

1. 在 Cloudflare 的 **Workers & Pages** 中创建 Pages 项目并连接本仓库。生产分支选择 `main`，构建命令填写 `npm run build:pages`，输出目录填写 `dist-pages`。将构建环境的 `NODE_VERSION` 设为 `24`。
2. 在本机项目目录运行 `npm run access:keys`，生成访问密钥和两项部署密钥。访问密钥用于登录，交给需要使用工作台的人。
3. 在 Pages 项目的 **Settings → Variables and Secrets** 中，为生产环境按加密类型分别添加 `DUTY_ACCESS_PROOF` 和 `DUTY_SESSION_KEY`，使用命令输出中与变量名对应的值。如需使用预览部署，在预览环境单独配置。把这些值保存在部署平台的密钥设置中。
4. 保存设置并重新部署。打开站点，输入第 2 步生成的访问密钥。更换密钥时，重新生成并更新两项部署密钥，再重新部署。

### 导入值班表

1. 点击 **导入值班表**，选择包含「值班时间、值班组长、值班人员」的 DOCX 表格或可选中文字的 PDF。班次支持中午、下午和晚上。Excel 和 CSV 可使用独立的「日期、班次、组长、人员」列，还可加入 `A`、`B多`、`B少`、`C`、`D` 分区列。导入窗口提供 CSV 模板。
2. 核对导入预览中的班次、组长、人员和人数，确认生效日期后保存。按星期循环的值班表默认使用本周，可按原表调整起止日期。重叠日期优先使用最近导入的表。
3. 选择当班日期和班次，调整人员及分区，填写值班情况。核对预览后复制总结或下载 TXT。

## 数据保存

值班表原文件由浏览器读取，解析后的排班、草稿、历史分区和来访姓名保存在当前浏览器的本地存储中。再次使用同一浏览器及站点地址可继续填写，各设备分别保存。

Pages 部署仅提供静态文件和访问校验。登录状态通过浏览器内有效期为 30 天的签名 Cookie 保存，Cookie 只包含到期时间和签名。应用无需数据库、文件存储或服务端会话表。

## 验证

`npm test` 检查值班表解析、出勤计算、报告生成和访问校验。使用 `node scripts/verify-roster.mjs <值班表路径>` 可在本机查看识别条数及校验结果。
