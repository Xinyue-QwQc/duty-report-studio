# 值班工作台

上传值班表，按日期和班次核对人员、分配区域，生成可复制或下载的日工作总结。

## 首次使用

### 在本机运行

安装 Node.js 22.13 或以上版本，在项目目录运行以下命令，再打开浏览器访问 `http://127.0.0.1:5173`。本机服务仅监听回环地址。共用资料保存在项目的 `.local-data/shared.sqlite` 中。

```sh
npm ci
npm run build
npm start
```

在 Windows 上完成构建后，也可双击 `启动工作台.cmd` 打开工作台。

### 部署到 Cloudflare Pages 并设置访问密钥

1. 在 Cloudflare 的 **Workers & Pages** 中创建 Pages 项目。连接本仓库时，选择生产分支 `main`，填写构建命令 `npm run build:pages`、输出目录 `dist-pages`，并将构建环境的 `NODE_VERSION` 设为 `24`。Direct Upload 项目可在本机构建后，用 Wrangler 上传 `dist-pages` 到生产分支。
2. 创建 D1 数据库，执行 `pages/schema.sql` 初始化表。在 Pages 项目的 **Settings → Bindings** 中为生产环境添加名为 `SHARED_DB` 的 D1 绑定，选择该数据库。使用预览环境时，为预览绑定独立的数据库。
3. 在本机运行 `npm run access:keys`，生成发给团队成员的访问密钥和两项部署密钥。在 Pages 项目的 **Settings → Variables and Secrets** 中将 `DUTY_ACCESS_PROOF` 和 `DUTY_SESSION_KEY` 添加为加密密钥，填入命令输出的对应值。
4. 重新部署后打开站点，输入团队访问密钥。更换访问密钥时，重新生成并更新两项部署密钥，再重新部署。

### 导入值班表

1. 打开「值班表」，点击 **上传值班表**。选择包含「值班时间、值班组长、值班人员」的 DOCX 表格或可选中文字的 PDF。班次支持中午、下午和晚上。Excel 和 CSV 可使用独立的「日期、班次、组长、人员」列，还可加入 `A`、`B多`、`B少`、`C`、`D` 分区列。
2. 核对导入预览中的班次、组长、人员和人数，确认生效日期后保存。排班保存到共用数据库，成员登录后可读取。按星期循环的值班表默认使用本周，可按原表调整起止日期。重叠日期优先使用最近导入的表。
3. 选择当班日期和班次，调整人员及分区，填写值班情况。核对预览后复制总结或下载 TXT。

## 数据保存

| 保存位置 | 保存内容 |
| --- | --- |
| Cloudflare D1 | 共用值班表的生效范围、班次、组长、人员和预设分区，以及在「来访人员」页维护的团队名录。 |
| 当前浏览器 | 个人填写历史。打开页面时从新总结开始，可手动套用以前的分区。 |
| 当前浏览器的签名 Cookie | 登录有效期和签名，有效期为 30 天。Pages 逐请求验签。 |

浏览器解析值班表原件，保存时提交排班字段到服务端。「人员与分区」的「刷新」将当前班次的到岗人员移回待分区。

## 验证

`npm test` 检查值班表解析、出勤计算、报告生成、访问校验和共用资料的保存范围。使用 `node scripts/verify-roster.mjs <值班表路径>` 可在本机查看识别条数及校验结果。
